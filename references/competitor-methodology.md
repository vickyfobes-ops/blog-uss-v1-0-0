# 竞品博客方法论

本文件把 Metalssculpture、YouFine、CN Statue 三个站点的公开博客优点提炼成可复用规则。只借鉴选题、结构、读者问题和转化路径，不复制原文、标题措辞、图片或未经验证的竞品数据。

## 三站各自值得保留的经验

### Metalssculpture：技术决策链

- 选题贴近采购和项目实施：材料对比、304/316、表面处理、制作流程、安装方式、分段运输、维护、预算与周期。
- 文章能从材料性能推进到项目动作，读者可以据此准备询价、设计和安装沟通。
- 适合建立“材料/形式 → 制作 → 安装 → 维护 → 风险”的技术型结构。
- 对复杂主题使用比较、工艺步骤和项目注意事项，内容有明确的实用价值。

### YouFine：问题型教育内容

- 大量使用 `How to`、`How long`、`Why` 和定义型问题，直接对应用户搜索语言。
- 覆盖材料知识、艺术理解、制作工艺、寿命、户外保护、委托流程和经典案例，适合做长尾主题集群。
- 文章把专业知识解释成普通买家能理解的问答，降低雕塑、材料和工艺的认知门槛。
- 适合使用“先解释概念，再给选型和行动建议”的教育型结构。

### CN Statue：场景化清单和商业转化

- 使用清单、分类、定义对比和场景选择，适合快速阅读和获取搜索流量。
- 常把内容连接到住宅入口、庭院、地产、喷泉、凉亭和定制雕塑等具体使用场景。
- 通过委托、定制、选材和维护主题自然引向询价或项目沟通。
- 适合使用“场景 → 选项 → 优缺点 → 选择建议 → 委托准备”的商业型结构。

## 三站共通的优点

1. **标题先匹配问题**：围绕材料、寿命、制作、维护、安装、场景和比较，而不是空泛的艺术评论。
2. **开头快速建立方向**：先回答读者最关心的结论或判断条件，再展开解释。
3. **内容分层**：概念解释、材料/形式差异、应用场景、制作或安装、维护和下一步行动逐层推进。
4. **加入可执行信息**：比较表、步骤、检查清单、选型条件、风险提醒和 FAQ。
5. **围绕真实决策写作**：回答“适不适合我的场地、预算、观看距离、气候、维护能力和施工条件”。
6. **形成主题集群**：一篇文章解决一个核心问题，同时为材料、制作、安装、维护和委托文章预留内部链接。
7. **教育和转化并存**：先帮助读者做出更好的判断，再引导其准备尺寸、场地、材料、预算、时间线和询价信息。

## Blog—USS 的写作结构

根据搜索意图选择一种主结构，不要把所有模式机械拼接。

### 技术比较型

适用于 Bronze vs Stainless Steel、304 vs 316、表面处理等主题：

`直接结论/判断条件 → 材料差异 → 场景适配 → 形式与制作 → 安装与结构 → 环境与维护 → 成本/时间线 → 委托清单 → CTA → Sources → FAQ`

### 问题教育型

适用于 How long、Why、How are statues made、What is contemporary sculpture 等主题：

`一句话解释 → 概念边界 → 影响因素 → 常见误区 → 实用判断 → 维护或委托建议 → CTA → Sources → FAQ`

### 场景清单型

适用于 Popular、Best、Types、入口/庭院/地产应用等主题：

`使用场景 → 选项分类 → 每项优缺点与适用条件 → 摆放/尺寸/维护提示 → 如何选择 → 委托准备 → CTA → Sources → FAQ`

## 每篇文章必须回答的决策问题

- 这件事适合什么场地、气候、观看距离和使用场景？
- 读者实际需要在什么选项之间做选择？
- 选择变化会怎样影响制作、安装、运输、维护、预算和时间线？
- 哪些内容是通用建议，哪些必须由项目条件或专业人员确认？
- 读者下一步应准备哪些信息，才能获得有效报价或设计建议？

## 竞品经验的使用边界

- 竞品文章只用于发现搜索问题、结构模式、内容缺口和商业主题。
- 不复述竞品的品牌自称、客户案例、价格、寿命、性能、排名或工程结论，除非有独立的一手来源验证。
- 每篇新文必须加入原创决策工具：比较矩阵、选择清单、公式、场景判断、维护动作或委托资料清单中的至少两项。
- 保持英语发布稿和中文审阅稿事实、数字、链接、CTA、FAQ、来源完全对应。
- 最后的 FAQ 必须回答真实用户问题；Sources 紧邻 FAQ 之前，不能把来源问题伪装成 FAQ。
